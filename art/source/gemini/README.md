# Raw Gemini output

Untouched originals from `art/gemini-prompt-pack.md`. Art never edits these; cleaned pieces go to `art/kit/`.

Name each file by its prompt code and a short name, for example:

- `A1-parchment.png`
- `B1-borders.png`
- `E0-template.png`
- `E7-mage.png`

Rerolls get a letter: `E7-mage-b.png`. Keep the rejects too if you like; Art picks the best and notes which one in `art/kit/README.md`.
